# Журнал работ по продвижению ПОЛАР (polarseafood.ru) — для отчётов заказчику

**Как вести (правило для агента):** каждая выполненная работа (SEO, карты и справочники,
реклама, контент, техничка, разработка, аналитика, документы) сразу дописывается сюда блоком
под датой: ЧТО сделано (конкретно, с цифрами) + ССЫЛКА (страница/кабинет/файл) + ЗАЧЕМ (польза
для бизнеса простыми словами, без жаргона). По команде «сделай отчёт» из этого файла
собирается подробный отчёт за период. Ничего не удалять — только дополнять. Раздел «Ожидает»
в конце — единственный редактируемый: сделанное переносить в даты. Раздел «Ожидает» — НЕ
источник статуса: прежде чем говорить «осталось сделать X», проверить X по факту.

## 2026-10-11 — аудит и новый сайт (до договора)

- **Аудит сайта polarseafood.ru: 147 страниц, 6 ключевых страниц в Lighthouse, 89 скриншотов телефон/десктоп** —
  `_materials/audit/Аудит и КП FutureFlow — ПОЛАР (11.10.2026).pdf`. *Зачем:* показать, где сайт теряет заявки
  (нет мобильной версии каталога, «Где купить», раздела для оптовиков; формы без согласия; 3 из 4 документов не открываются).

  производство не подтверждено, в Google дубль с рейтингом 1,0 — это прямые потери звонков.
- **Новый сайт: 7 страниц, каталог 112 позиций с поиском, фильтрами и запросом прайса по позициям** — `site/`.
  Lighthouse на телефоне 90–94 (было 49–55), главный экран 3,4 с (было 10,9 с). *Зачем:* сайт, который продаёт
  и закупщику, и покупателю в магазине.
- **КП: 60 000 ₽/мес за всё цифровое, приоритет в разработке (ИИ, автоматизация, CRM, цифровой двойник)** — последний раздел PDF.
